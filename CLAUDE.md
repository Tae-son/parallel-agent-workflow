# parallel-agent-workflow

This repository is the kit itself and uses its own rules. Read `CONTRIBUTING.md` before
changing anything. In short: work on a branch in your own worktree, keep to the Allowed
paths in your brief, run `npm run verify`, open a pull request with the template, and never
merge, push to `main`, or run `scripts/land.sh`. Everything under `scripts/`, `tests/`,
`.github/`, `.githooks/` and `.claude/` is a gate file.
